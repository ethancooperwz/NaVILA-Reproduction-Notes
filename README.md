# NaVILA 复现笔记

本仓库整理 [NaVILA](https://github.com/AnjieCheng/NaVILA) 的中文复现流程，覆盖环境配置、数据准备、公开权重推理评测和结果分析。

> 已于 2026-10-31 完成官方 NaVILA-8B-8F 权重在 R2R-CE `val_unseen` 全部 1839 条任务上的评测。本次属于公开权重的高层导航评测复现，不包含重新训练、底层运动策略、Isaac 完整系统或真机部署。

## 本地评测结果

| 指标 | 论文 R2R-CE Val-Unseen | 本地实测 |
| --- | ---: | ---: |
| NE ↓ | 5.22 m | 5.2144 m |
| OS ↑ | 62.50% | 61.61% |
| SR ↑ | 54.00% | 54.11% |
| SPL ↑ | 49.00% | 49.39% |
| nDTW ↑ | 该表未报告 R2R 值 | 63.79% |

论文参考值来自 [NaVILA 论文表 I](https://arxiv.org/html/2412.04453v2)。本地使用两张 RTX 3090、FP16、8 帧输入，两个分片分别完成 920 和 919 条任务，已检查无重复和遗漏。指标接近论文，但不构成性能提升结论；完整配置与检查记录见第 6 篇。

本地新增的逐条进度保存与恢复不是官方原始功能。本文档记录了相关行为与兼容修改；复现时应区分本地修改版本和未经修改的官方源码。
