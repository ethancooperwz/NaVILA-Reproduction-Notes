# NaVILA 论文介绍

## 1. 论文信息

- 论文：**NaVILA: Legged Robot Vision-Language-Action Model for Navigation**
- arXiv：[2412.04453](https://arxiv.org/abs/2412.04453)
- 代码：[AnjieCheng/NaVILA](https://github.com/AnjieCheng/NaVILA)
- 项目主页：[navila-bot.github.io](https://navila-bot.github.io/)
- 任务：让腿式机器人根据自然语言指令和视觉观察，在未知环境中自主导航到目标位置。

本文区分 NaVILA 的论文方法与本仓库的复现范围。本仓库使用官方权重 a8cheng/navila-llama3-8b-8f，在 Habitat 中评测 R2R-CE val_unseen；数据采用 R2R-VLNCE v1-3。当前复现不包含底层运动策略训练、VLN-CE-Isaac 评测或真实机器人部署。

## 2. NaVILA 解决什么问题

如何将基于 VLM 的视觉语言导航能力有效迁移到真实腿式机器人，使其能够在复杂、未知环境中执行长距离语言导航任务？
打通了“语言指令 → 视觉导航决策 → 中层空间动作 → 腿式机器人运动控制”这条链路，使基于 VLM 的导航方法能够应用于真实腿式机器人。


导航泛化能力受数据限制。 传统 VLN 依赖仿真导航数据，真实机器人导航数据获取昂贵，难以覆盖复杂、多样的真实场景。

### 视觉语言导航的泛化问题
- 部分已有 VLN 方法依赖深度、全景观察、里程计或仿真中预训练的 waypoint predictor。
- NaVILA 利用预训练 VLM（VILA），结合导航数据和人类第一视角视频进行微调，使机器人能够仅依靠 RGB 图像和语言指令进行高层导航决策。
### VLM 输出与机器人底层控制之间的衔接问题
- VLM 擅长理解视觉和语言，但不适合直接预测复杂的机器人关节动作。
- NaVILA 让 VLM 输出距离、角度等中层动作，再由底层运动策略执行。
- 这种解耦使同一个高层 VLA 可以适配不同形态的机器人。
### 复杂地形中的运动执行问题
- 传统 VLN 研究通常简化了机器人的物理运动过程。
- NaVILA 引入基于 LiDAR 高度图的 RL Locomotion Policy，使机器人能够在执行导航指令时进行局部地形适应和一定程度的避障。
- 但它没有提供严格的安全保证，也没有解决完整的全局避障规划问题。

### 训练高层VLA模型
- 基础模型：VILA
- 训练方式：监督微调SFT
- 训练数据：R2R-CE、RxR-CE、人类第一视角视频，以及辅助导航和通用视觉语言数据
- 输入：自然语言指令 + 历史 RGB 图像 + 当前 RGB 图像。
- 输出：中层导航动作，例如 Move forward 75 cm。
### 底层运动策略：以论文介绍的 Go2 策略为例
- 训练算法：PPO。
- 训练环境：Isaac Lab。
- 输入：目标速度 + 机器人本体感知 + LiDAR 高度图。
- 输出：机器人关节目标位置。
- 作用：速度跟踪、稳定运动、地形适应以及局部避障。
### 将两个模型集成并进行实验验证
- 通过语言形式的中层动作，将高层 VLA 和底层 RL 解耦。
- 构建 VLN-CE-Isaac，在具有真实机器人动力学的仿真环境中验证完整系统。
- 在 Go2、H1、Booster T1 等机器人平台上验证方法的适用性，并开展真实环境实验。

## 3. NaVILA 创新

### 语言中层动作与双频控制
高层 VLA 低频输出带距离、角度的语言动作，将其转换为速度指令及执行时长；底层运动策略实时执行，实现导航理解与机器人控制的解耦。
### 面向导航的观察组织与人类视频监督
区分当前观察与历史观察，并从人类第一视角视频提取导航监督，使真实视频能够参与连续导航模型的训练。
### 面向腿式机器人的完整系统评估
构建 VLN-CE-Isaac，评估包含机器人动力学和底层控制的导航系统，并开展真实机器人实验。

## 4. 输入、输出与动作执行

高层 VLA 的输入包括语言导航指令、历史 RGB 观察和当前 RGB
观察。当前公开的 8 帧评测配置使用 7 个历史帧位置和 1 个当前帧；
历史不足时使用黑色图像补齐。

模型生成带空间参数的自然语言动作，例如：

- The next action is move forward 75 cm.
- The next action is turn left 30 degree.
- I think I should stop because I have finished the instruction.

Habitat 评测代码解析动作类别及距离、角度，再转换为基本动作执行：

| Habitat 动作 | 编号 | 基本执行单位 |
| --- | --- | --- |
| STOP | 0 | 停止当前任务 |
| MOVE_FORWARD | 1 | 前进 0.25 m |
| TURN_LEFT | 2 | 左转 15° |
| TURN_RIGHT | 3 | 右转 15° |

例如，“前进 75 cm”被执行为三次前进 0.25 m。
因此，应区分模型生成的语言动作与仿真器执行的基本动作。

Habitat 配置中虽然存在深度传感器，但当前高层 VLA 的模型输入
使用 RGB 图像，而非深度、相机位姿或内参。

## 5. 训练数据与训练流程

NaVILA 基于 VILA 进行面向导航的监督微调。VILA 的连接器初始化和视觉语言预训练属于继承的基础训练阶段，不能与 NaVILA 的导航微调混为一谈。

官方公开训练脚本从 a8cheng/navila-siglip-llama3-8b-v1.5-pretrain 开始，使用 Llama 3 8B 语言模型和 SigLIP 视觉编码器，并微调视觉编码器、投影模块和语言模型。

微调数据包括 R2R、RxR、EnvDrop、人类第一视角导航视频、ScanQA，以及 Video-ChatGPT、ShareGPTVideo、ShareGPT4V 等视觉语言数据。

仿真导航监督通过 shortest-path follower 生成；连续同类基本动作被合并为带距离或角度的语言标签，并进行动作标签平衡。

对人类第一视角视频，作者先进行轨迹片段采样，再利用相机位姿估计提取运动信息，并通过视觉语言描述和语言改写生成导航指令，从而构造用于连续导航训练的监督样本。

## 6. 评测数据与指标

主要基准是基于 Matterport3D 场景的 R2R-CE 和 RxR-CE，重点考察 `val_unseen`，即在训练中未出现过的室内场景上泛化。

| 指标 | 含义 | 趋势 |
| --- | --- | --- |
| NE | 结束位置到目标的最短路径距离（米） | 越低越好 |
| OS | 轨迹中是否曾进入成功半径 | 越高越好 |
| SR | 执行 `STOP` 时是否位于成功半径内 | 越高越好 |
| SPL | 用路径效率加权后的成功率 | 越高越好 |
| nDTW | 预测轨迹与参考轨迹的归一化相似度，RxR 常用 | 越高越好 |

OS 高但 SR 低通常意味着智能体曾到达目标附近，却没有及时停止；SR 高但 SPL 偏低则说明绕路较多。

当前 R2R 评测也计算 nDTW，并非仅在 RxR 中使用。SR、OS、SPL 和 nDTW 的原始结果通常是 0～1 的数值；与论文百分数形式的表格比较时，需要统一单位。NE 以米计。

Habitat 上的高层导航结果、Isaac 中的完整机器人结果和真实机器人结果，要分别讨论。 不能用当前 R2R 评测代表整篇论文的完整复现。
