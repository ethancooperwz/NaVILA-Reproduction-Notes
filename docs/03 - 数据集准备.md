# 数据集准备

本文针对官方 NaVILA checkpoint 在 Habitat 中的 R2R-CE `val_unseen` 评测。先完成[环境配置](02%20-%20环境配置.md)。本地已下载的模型、场景和标注可直接复用，无需重复下载。

## 1. 区分权重、场景与任务标注

| 类型 | 内容 | R2R 评测是否必需 |
| --- | --- | --- |
| 模型权重 | `a8cheng/navila-llama3-8b-8f`，含语言模型、视觉编码器、投影模块和 tokenizer | 是 |
| MP3D 场景 | 三维场景 `.glb` 和配套导航网格 `.navmesh` | 是 |
| R2R 任务标注 | `val_unseen.json.gz`，包含指令、场景、起终点等 | 是 |
| R2R GT 标注 | `val_unseen_gt.json.gz`，包含参考轨迹、动作等，供 nDTW 计算使用 | 是，当前配置启用了 nDTW |
| 导航训练图像与辅助数据 | 微调所用的视频、帧图像及标注 | 仅重新训练时需要 |

`R2R_VLNCE_v1-3_preprocessed.zip` 是任务与参考轨迹的预处理标注包，不是 MP3D 场景，也不是模型权重。当前评测不需要 HM3D、ScaleVLN 或 StreamVLN 的训练轨迹数据。

## 2. 约定路径

`NAVILA_ROOT` 必须指向 NaVILA 源码目录，不是外层复现笔记目录。以下共用数据根目录采用本机实际路径；其他机器请替换：

```bash
conda activate navila-eval
unset PYTHONPATH

export NAVILA_ROOT=/你的实际路径/NaVILA
export VLN_DATA_ROOT=/media/ethan/Data01/VLN_data
export R2R_ROOT="$VLN_DATA_ROOT/datasets/r2r"
export SCENE_ROOT="$VLN_DATA_ROOT/scene_datasets"

cd "$NAVILA_ROOT"
```

本地共用目录结构：

```text
VLN_data/
├── datasets/
│   └── r2r/
│       ├── train/
│       │   ├── train.json.gz
│       │   └── train_gt.json.gz
│       ├── val_seen/
│       │   ├── val_seen.json.gz
│       │   └── val_seen_gt.json.gz
│       ├── val_unseen/
│       │   ├── val_unseen.json.gz
│       │   └── val_unseen_gt.json.gz
│       └── test/
│           └── test.json.gz
└── scene_datasets/
    └── mp3d/
        ├── 17DRP5sb8fy/
        │   ├── 17DRP5sb8fy.glb
        │   └── 17DRP5sb8fy.navmesh
        └── ...
```

已有其他存储布局时，不必强行改名，只需设置 `R2R_ROOT` 和 `SCENE_ROOT` 为实际路径。外置盘或数据盘在评测前需要保持挂载。

## 3. 下载官方模型权重

完整评测权重来自 [a8cheng/navila-llama3-8b-8f](https://huggingface.co/a8cheng/navila-llama3-8b-8f)，不要与用于重新微调的 `navila-siglip-llama3-8b-v1.5-pretrain` 混用。

```bash
cd "$NAVILA_ROOT"

HF_HUB_DOWNLOAD_TIMEOUT=120 python - <<'PY'
from huggingface_hub import snapshot_download

snapshot_download(
    repo_id="a8cheng/navila-llama3-8b-8f",
    local_dir="checkpoints/navila-llama3-8b-8f",
    max_workers=2,
)
PY
```

下载中断后可重新执行同一命令，下载器会复用已完成的有效文件。模型目录应包含以下关键文件；下载时保留完整仓库，不要只下载语言模型分片：

```text
checkpoints/navila-llama3-8b-8f/
├── config.json
├── llm/
│   ├── config.json
│   ├── model-00001-of-00004.safetensors
│   ├── model-00002-of-00004.safetensors
│   ├── model-00003-of-00004.safetensors
│   ├── model-00004-of-00004.safetensors
│   ├── model.safetensors.index.json
│   ├── tokenizer.json
│   └── tokenizer_config.json
├── mm_projector/
│   ├── config.json
│   └── model.safetensors
└── vision_tower/
    ├── config.json
    ├── model.safetensors
    └── preprocessor_config.json
```

## 4. 准备 Matterport3D 场景

已有 MP3D 时先复用。本机位于 `$SCENE_ROOT/mp3d`，曾检查到 90 个场景 `.glb` 及 90 个 `.navmesh`。这是本地检查记录，其他机器仍应执行第 7 节的完整性检查。

尚未下载时，先在 [Matterport3D 官方页面](https://niessner.github.io/Matterport/) 阅读许可并申请下载权限。获得官方 `download_mp.py` 后，旧版下载器可使用单独的 Python 2.7 环境：

```bash
conda create -n mp3d-download python=2.7 -y
conda activate mp3d-download

python /你的实际路径/download_mp.py \
  -o /你的实际路径/mp3d_download \
  --task_data habitat
```

命令按本机已有旧版下载器的 `--task_data` 参数编写；其他版本先运行 `--help` 核对参数。按提示确认许可。该下载器可能在 Habitat task data 完成后询问是否继续下载完整原始扫描；仅做本次评测时，可在确认 task data 已完整下载后退出，不需要继续下载原始扫描。

解压 Habitat 场景资产，将包含各场景 ID 子目录的那一层整理为 `$SCENE_ROOT/mp3d`。避免出现 `mp3d/mp3d/<场景 ID>` 的多余层级。目标示例：

```text
/media/ethan/Data01/VLN_data/scene_datasets/mp3d/17DRP5sb8fy/17DRP5sb8fy.glb
/media/ethan/Data01/VLN_data/scene_datasets/mp3d/17DRP5sb8fy/17DRP5sb8fy.navmesh
```

下载结束后切回模型评测环境：

```bash
conda activate navila-eval
unset PYTHONPATH
```

## 5. 准备 R2R 预处理标注及 GT

### 下载入口与用途

使用 VLN-CE 官方提供的 [R2R_VLNCE_v1-3_preprocessed.zip](https://drive.google.com/file/d/1fo8F4NKgZDH-bPSdVU3cONAkt5EW-tyr/view)，约 250 MiB（262 MB）。它包含 R2R 各划分、参考轨迹、EnvDrop 增广数据和辅助词向量，不能简单将整个压缩包称为“EnvDrop 数据”。

可通过浏览器下载，或在 NaVILA 根目录执行：

```bash
cd "$NAVILA_ROOT"
mkdir -p evaluation/downloads

python -m gdown \
  'https://drive.google.com/uc?id=1fo8F4NKgZDH-bPSdVU3cONAkt5EW-tyr' \
  -O evaluation/downloads/R2R_VLNCE_v1-3_preprocessed.zip
```

先解压到整理目录，避免直接覆盖共用数据：

```bash
python -m zipfile -e \
  evaluation/downloads/R2R_VLNCE_v1-3_preprocessed.zip \
  evaluation/downloads/r2r_preprocessed
```

解压后的顶层目录是 `R2R_VLNCE_v1-3_preprocessed`。里面的 `.json.gz` 保持压缩格式，不要继续解压为裸 JSON。

### 全新准备与复用已有任务文件

- **全新准备**：将解压后的整个目录放入共用 `datasets` 目录。可以保留原名，并把 `R2R_ROOT` 改为其实际路径；若共用目录尚无 `r2r`，也可以将它命名为 `r2r`。
- **已有 R2R 任务文件**：先核对版本和任务内容，再补充缺失的 GT，不要直接覆盖现有同名标注。本地已比较官方包与原有 train、val_seen、val_unseen：任务 ID、场景、起终点及参考路径一致，差异仅在 `instruction_tokens`，因此只补充了三份 GT。

本地补充文件的对应关系：

| 解压包中的文件 | 共用目录中的位置 |
| --- | --- |
| `train/train_gt.json.gz` | `$R2R_ROOT/train/train_gt.json.gz` |
| `val_seen/val_seen_gt.json.gz` | `$R2R_ROOT/val_seen/val_seen_gt.json.gz` |
| `val_unseen/val_unseen_gt.json.gz` | `$R2R_ROOT/val_unseen/val_unseen_gt.json.gz` |

同名压缩文件的大小不同不一定代表损坏；压缩方式或字段内容变化都可能改变大小。本地两份任务文件的 token 差异不会改变当前 NaVILA 的语言输入，因为模型读取 `instruction_text` 并使用自己的 tokenizer 重新编码。这不能推广到直接依赖预编码 token 和配套词表的其他模型。

`*_gt.json.gz` 保存参考位置序列等信息，用于计算 nDTW，与普通任务 JSON 不能互相替代。当前配置读取不到 `val_unseen_gt.json.gz` 时会直接报错。官方包中的 `test` 没有 `test_gt.json.gz`，不需要自行构造或改名补齐。本次只评测 `val_unseen`。

## 6. 将共用目录链接到 NaVILA

从 `evaluation` 目录启动时，配置 `habitat_extensions/config/vlnce_task.yaml` 读取：

```text
data/datasets/R2R_VLNCE_v1-3_preprocessed/{split}/{split}.json.gz
data/datasets/R2R_VLNCE_v1-3_preprocessed/{split}/{split}_gt.json.gz
data/scene_datasets/
```

项目内对应 `NaVILA/evaluation/data/`，不是 `NaVILA/data/`，也不是 StreamVLN 的 `config/vln_r2r.yaml`。

确认第 2 节路径变量仍有效后执行以下命令。链接复用共用数据，不复制大文件；已有不同目录或链接时会停止，不覆盖或删除：

```bash
cd "$NAVILA_ROOT/evaluation"

python - <<'PY'
import os
from pathlib import Path

links = [
    (Path("data/scene_datasets"), Path(os.environ["SCENE_ROOT"])),
    (Path("data/datasets/R2R_VLNCE_v1-3_preprocessed"),
     Path(os.environ["R2R_ROOT"])),
]

for dest, source in links:
    if not source.is_dir():
        raise FileNotFoundError(f"共用目录不存在或数据盘未挂载：{source}")
    if dest.is_symlink() or dest.exists():
        if dest.resolve() != source.resolve():
            raise RuntimeError(f"已有不同目录或链接，请手动检查：{dest}")

for dest, source in links:
    dest.parent.mkdir(parents=True, exist_ok=True)
    if not dest.is_symlink() and not dest.exists():
        dest.symlink_to(source.resolve(), target_is_directory=True)
    print(f"{dest} -> {dest.resolve()}")
PY
```

链接后的结构：

```text
NaVILA/evaluation/data/
├── connectivity_graphs.pkl
├── datasets/
│   └── R2R_VLNCE_v1-3_preprocessed -> 共用 datasets/r2r
└── scene_datasets -> 共用 scene_datasets
```

保留源码自带的 `connectivity_graphs.pkl`，当前俯视轨迹可视化会使用它。不要用整个共用 `data` 目录覆盖项目内的 `evaluation/data`。

## 7. 完整性检查

以下检查不加载模型、不启动 GPU 仿真，也不修改数据。它检查模型关键文件及分片索引、验证集任务数、GT 对应关系，以及所有引用场景的 GLB 和导航网格：

```bash
cd "$NAVILA_ROOT/evaluation"

python - <<'PY'
import gzip
import json
from pathlib import Path

model = Path("../checkpoints/navila-llama3-8b-8f")
required = [
    "config.json",
    "llm/config.json",
    "llm/model.safetensors.index.json",
    "llm/tokenizer.json",
    "llm/tokenizer_config.json",
    "mm_projector/config.json",
    "mm_projector/model.safetensors",
    "vision_tower/config.json",
    "vision_tower/model.safetensors",
    "vision_tower/preprocessor_config.json",
]
for name in required:
    path = model / name
    assert path.is_file() and path.stat().st_size > 0, f"模型文件缺失或为空：{path}"

index = json.loads((model / "llm/model.safetensors.index.json").read_text())
shards = set(index["weight_map"].values())
for name in shards:
    path = model / "llm" / name
    assert path.is_file() and path.stat().st_size > 0, f"模型分片缺失或为空：{path}"
print("语言模型分片数：", len(shards))

root = Path("data/datasets/R2R_VLNCE_v1-3_preprocessed/val_unseen")
with gzip.open(root / "val_unseen.json.gz", "rt") as f:
    episodes = json.load(f)["episodes"]
with gzip.open(root / "val_unseen_gt.json.gz", "rt") as f:
    gt = json.load(f)

ids = [str(ep["episode_id"]) for ep in episodes]
assert len(ids) == len(set(ids)) == 1839, "任务数异常或存在重复 episode ID"
missing_gt = sorted(set(ids) - set(gt))
assert not missing_gt, f"缺少 GT：{missing_gt[:10]}"

scenes = set()
for ep in episodes:
    assert ep["instruction"]["instruction_text"], "导航指令为空"
    locations = gt[str(ep["episode_id"])]["locations"]
    assert locations and all(len(p) == 3 for p in locations), "参考轨迹位置格式异常"
    scene_id = ep["scene_id"]
    prefix = "data/scene_datasets/"
    if scene_id.startswith(prefix):
        scene_id = scene_id[len(prefix):]
    scene = Path("data/scene_datasets") / scene_id
    scenes.add(scene)

for scene in scenes:
    assert scene.is_file(), f"缺少场景：{scene}"
    assert scene.with_suffix(".navmesh").is_file(), f"缺少导航网格：{scene}"

assert Path("data/connectivity_graphs.pkl").is_file(), "缺少可视化连接图"
print("验证集任务数：", len(episodes))
print("对应参考轨迹全部存在；引用场景数：", len(scenes))
print("模型关键文件、任务标注、GT 和场景路径检查通过")
PY
```

文件存在和索引检查不等同于权重内容校验，也不能验证 EGL 渲染或模型推理是否正常。检查通过后，按[模型推理与测评](04%20-%20模型推理与测评.md)跑通实际任务。

## 8. RxR 与重新训练的数据（可选）

当前 R2R 评测无需下载本节数据。

- **RxR 评测**：从 [VLN-CE 官方说明](https://github.com/jacobkrantz/VLN-CE#data)下载 [RxR_VLNCE_v0](https://drive.google.com/file/d/145xzLjxBaNTbVgBfQ8e9EsBAV8W-SM0t/view)。NaVILA 默认路径为 `evaluation/data/datasets/RxR_VLNCE_v0/`，对应文件为 `{split}_guide.json.gz` 和 `{split}_guide_gt.json.gz`；语言、角色和 split 需与所选 RxR 配置一致，不要直接套用 StreamVLN 的目录重命名规则。
- **NaVILA 导航微调**：参考 [NaVILA-Dataset](https://huggingface.co/datasets/a8cheng/NaVILA-Dataset) 和官方训练说明，准备 R2R、RxR、EnvDrop、人类视频、ScanQA 及通用视觉语言数据；在 `llava/data/datasets_mixture.py` 配置路径，通过 `scripts/train/sft_8frames.sh` 训练。
- **原始视觉数据**：人类视频提供视频 ID 和标注，需按官方流程自行获取视频、提取帧；EnvDrop 视频需利用导航标注和场景渲染。训练标注不能代替缺失的视频或图像。

这些属于训练或扩展评测准备，不是当前公开 checkpoint 的 R2R 评测前置条件。
