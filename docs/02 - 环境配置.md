# 环境配置

## 1. 推荐软硬件

本地复现使用 Ubuntu 22.04、Python 3.10、PyTorch 2.3.0/cu121、Habitat-Sim/Lab 0.1.7，以及两张 RTX 3090 24 GB。当前模型以 FP16 加载。官方多卡评测脚本按任务分片，每张卡独立加载一份模型，因此显存不会自动合并；每张卡都需要容纳模型、推理缓存和仿真渲染开销。

下文记录本地跑通时采用的版本与兼容修改，不代表所有硬件都适用。已经完成安装的环境无需从头重复执行。

先确认驱动和基础工具：

```bash
nvidia-smi
conda --version
git --version
gcc --version
nvcc --version
```

`nvidia-smi` 显示的 CUDA 版本表示驱动支持能力，不等于已安装的 Toolkit 版本。此时若找不到 `nvcc`，可在第 7 节安装 CUDA Toolkit 后再次检查。

下文假设已下载 [NaVILA 官方源码](https://github.com/AnjieCheng/NaVILA)。尚未下载时，先在计划存放源码的目录执行：

```bash
git clone https://github.com/AnjieCheng/NaVILA.git
```

后续命令约定源码目录为：

```bash
export NAVILA_ROOT=/你的实际路径/NaVILA
cd "$NAVILA_ROOT"
```

请将其改为自己的绝对路径，不要直接照搬作者或本文原来的 `/home/...` 路径。

## 2. 创建 Conda 环境

```bash
conda create -n navila-eval python=3.10 -y
conda activate navila-eval

# 隔离 ~/.local 中的用户包，避免覆盖 Conda 环境。
conda env config vars set PYTHONNOUSERSITE=1
conda deactivate
conda activate navila-eval
unset PYTHONPATH

python -m pip install \
  "pip==24.0" \
  "setuptools==69.5.1" \
  "wheel==0.38.4" \
  "cmake<4" \

python -m pip install \
  torch==2.3.0 torchvision==0.18.0 numpy==1.26.0 \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
```

## 3. 安装 Habitat-Sim 0.1.7

`headless` 适合不需要弹出仿真窗口的评测；它仍需正确的 NVIDIA 驱动和 EGL 支持。

```bash
sudo apt-get update
sudo apt-get install -y \
  build-essential git pkg-config \
  libjpeg-dev libglm-dev \
  libegl1-mesa-dev libgl1-mesa-dev \
  mesa-utils xorg-dev freeglut3-dev

cd "$NAVILA_ROOT"
mkdir -p third_party
cd third_party
git clone --branch v0.1.7 --recursive \
  https://github.com/facebookresearch/habitat-sim.git
cd habitat-sim

python -m pip install \
  -r requirements.txt \
  "numpy==1.26.0" \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple

python setup.py install --headless

cd "$NAVILA_ROOT"
python evaluation/scripts/habitat_sim_autofix.py
```

补丁输出应包含 `Replaced ...`；若提示找不到文件，先检查安装路径，不要把补丁执行失败当作成功。本地 `v0.1.7` 与 `challenge-2021` 标签指向同一提交，`git describe` 显示后者不代表版本错误。

## 4. 安装 Habitat-Lab 0.1.7

```bash
cd "$NAVILA_ROOT/third_party"

git clone --branch v0.1.7 \
  https://github.com/facebookresearch/habitat-lab.git

cd habitat-lab

python -m pip install \
  -r requirements.txt "numpy==1.26.0" \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
```

安装 baselines 前，需要调整旧依赖。TensorFlow 1.13.1 没有 Python 3.10 安装包；本地使用 TensorBoard，并在第 9 节将评测代码中未直接使用的 TensorFlow 导入改为可选导入。以下命令同时固定 MoviePy 1.x，并将 WebDataset 调整为 NaVILA 评测使用的版本：

```bash
python - <<'PY'
from pathlib import Path

p = Path("habitat_baselines/rl/requirements.txt")
text = p.read_text()
text = text.replace("moviepy>=1.0.1", "moviepy==1.0.3")
text = text.replace("# full tensorflow required for tensorboard video support\n", "")
text = text.replace("tensorflow==1.13.1\n", "")
text = text.replace("tb-nightly", "tensorboard==2.15.2")
p.write_text(text)

p = Path("habitat_baselines/il/requirements.txt")
p.write_text(p.read_text().replace("webdataset==0.1.40", "webdataset==0.1.103"))
PY

# 仍在 habitat-lab 目录内执行
python -m pip install \
  -r habitat_baselines/rl/requirements.txt \
  -r habitat_baselines/rl/ddppo/requirements.txt \
  -r habitat_baselines/il/requirements.txt \
  "numpy==1.26.0" \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple

python setup.py develop --all
```

安装后不要删除或移动这个源码目录，否则 editable install 会失效。

## 6. 安装 FlashAttention

预编译 wheel 必须选择兼容 Python、PyTorch、CUDA 和 C++ ABI 的构建。下面是本地 Python 3.10、PyTorch 2.3.0/cu121 环境已验证可导入的官方 wheel，不能仅靠修改文件名适配其他版本。`--no-deps` 用于保留已经安装的模型依赖。

```bash
python -m pip install --no-deps \
  "https://github.com/Dao-AILab/flash-attention/releases/download/v2.5.8/flash_attn-2.5.8+cu122torch2.3cxx11abiFALSE-cp310-cp310-linux_x86_64.whl"
```


## 7. 安装 DeepSpeed 并应用模型补丁

DeepSpeed 0.9.5 即使设置 `DS_BUILD_OPS=0`，安装脚本仍会检查 CUDA Toolkit，因此先安装 Toolkit 并设置 `CUDA_HOME`。本地固定 W&B 版本，以减少旧版 Pydantic 环境中的依赖回溯。

```bash
conda install -c nvidia cuda-toolkit=12.1 -y

export CUDA_HOME="$CONDA_PREFIX"
export PATH="$CUDA_HOME/bin:$PATH"
nvcc --version

DS_BUILD_OPS=0 python -m pip install \
  deepspeed==0.9.5 ninja "wandb==0.26.1" \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple

cd "$NAVILA_ROOT"

site_pkg_path=$(python -c 'import site; print(site.getsitepackages()[0])')

cp -rv ./llava/train/transformers_replace/. \
  "$site_pkg_path/transformers/"

cp -rv ./llava/train/deepspeed_replace/. \
  "$site_pkg_path/deepspeed/"
```

上述 Transformers 和 DeepSpeed 替换文件来自 NaVILA 仓库；应在对应包安装完成后复制。后续若重新安装这两个包，需要重新应用对应补丁。重新激活环境后若要编译 CUDA 扩展，也需重新设置本节的 `CUDA_HOME` 和 `PATH`。

## 8. 安装评测依赖

保留官方依赖文件，生成本地版本，跳过 TensorFlow 和 `tb-nightly`。随后固定已验证的兼容版本；此步骤应放在 VILA 安装之后，避免 WebDataset 再次被升级。

```bash
cd "$NAVILA_ROOT"

python - <<'PY'
from pathlib import Path

lines = Path("evaluation/requirements.txt").read_text().splitlines()
lines = [
    line for line in lines
    if line.strip().lower() not in {"tensorflow", "tb-nightly"}
]
Path("evaluation/requirements.local.txt").write_text(
    "\n".join(lines) + "\n"
)
PY

python -m pip install \
  -r evaluation/requirements.local.txt \
  "numpy==1.26.0" \
  "opencv-python==4.8.0.74" \
  "tensorboard==2.15.2" \
  "webdataset==0.1.103" \
  "joblib==1.3.2" \
  "huggingface-hub==0.36.2" \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
```

`joblib==1.3.2` 用于避免新版 Joblib 与 Gym 0.17.3 所需旧版 Cloudpickle 的声明冲突；`huggingface-hub==0.36.2` 满足 Transformers 4.37.2 的 `<1.0` 要求。

## 9. 本地 TensorFlow 导入兼容补丁

评测入口会导入三个旧训练器，它们原本强制导入 TensorFlow，但没有直接使用 `tf`。以下本地补丁仅在 TensorFlow 本身未安装时允许继续导入，不屏蔽其他缺包错误。

```bash
cd "$NAVILA_ROOT"

python - <<'PY'
from pathlib import Path

root = Path("evaluation/vlnce_baselines")
old = "    import tensorflow as tf  # noqa: F401\n"
new = (
    "    try:\n"
    "        import tensorflow as tf  # noqa: F401\n"
    "    except ModuleNotFoundError as exc:\n"
    '        if exc.name != "tensorflow":\n'
    "            raise\n"
)

pending = []
for name in ("common/base_il_trainer.py", "dagger_trainer.py", "recollect_trainer.py"):
    path = root / name
    text = path.read_text()
    if new in text:
        print(f"已应用：{path}")
        continue
    if text.count(old) != 1:
        raise RuntimeError(f"未找到唯一的预期导入语句，请手动检查：{path}")
    pending.append((path, text.replace(old, new)))

for path, text in pending:
    path.write_text(text)
    print(f"已修改：{path}")
PY
```

## 10. 环境检查与版本记录

```bash
cd "$NAVILA_ROOT/evaluation"

python - <<'PY'
import site
import sys
import torch
import habitat
import habitat_sim
import habitat_baselines
import transformers
import deepspeed
import flash_attn
import numpy

print("Python:", sys.executable)
print("用户包启用:", site.ENABLE_USER_SITE)
print("PyTorch:", torch.__version__)
print("CUDA runtime:", torch.version.cuda)
print("CUDA available:", torch.cuda.is_available())
print("GPU count:", torch.cuda.device_count())
print("NumPy:", numpy.__version__)
print("Transformers:", transformers.__version__)
print("DeepSpeed:", deepspeed.__version__)
print("FlashAttention:", flash_attn.__version__)
print("Habitat 核心模块导入通过")
PY

python run.py --help
python -m pip check
```

预期用户包启用为 `False`、CUDA 可用，版本分别为 PyTorch `2.3.0+cu121`、NumPy `1.26.0`、Transformers `4.37.2`、DeepSpeed `0.9.5`、FlashAttention `2.5.8`。GPU 数量取决于机器配置和 `CUDA_VISIBLE_DEVICES`。

`pip check` 会报告 VILA 声明要求 `webdataset==0.2.86`，而本地评测使用 `0.1.103`。这是 NaVILA 官方评测降级要求带来的已知声明冲突，保留 `0.1.103`；其他冲突应逐项检查。不要直接升级 Transformers、Gym 或 Habitat 来消除提示。

`run.py --help` 通过仅表示导入及参数入口正常，不代表模型推理、显存容量或 EGL 场景渲染已通过。后续按[数据集准备](03%20-%20数据集准备.md)和[模型推理与测评](04%20-%20模型推理与测评.md)验证完整流程；本地单卡设备加载调整及中断恢复修改应记录在评测文档中。
